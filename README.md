# Aminoglycoside QSP–ML: Bayesian PopPK + Interpretable Machine Learning for Precision Dosing

Code, synthetic data, trained model artifacts, and analysis results accompanying the manuscript:

> Srinivasan A, Biswas A, Mishra A, Anil A. *A Simulation-Based Quantitative Systems Pharmacology–Machine Learning Framework for Aminoglycoside Precision Dosing in Critical Illness: Development and In-Silico Qualification.* Submitted to **Pharmacological Research** (Elsevier), 2026.

This repository accompanies the submission and is intended for editorial review, replication of the reported analyses, and adaptation to other settings. **No real patient data are included.** The cohort is fully synthetic, generated by `generate_synthetic_data_python.py` from published aminoglycoside pharmacokinetic distributions.

---

## Framing — read before running

The framework is an **in-silico qualification** of an integrated Bayesian population pharmacokinetic (PopPK) + interpretable machine-learning pipeline using a synthetic ICU cohort. It is **not** a clinical validation study. Reported model performance reflects recovery of PK/PD relationships embedded in the synthetic outcome simulator and constitutes a methodological upper bound. **Prospective validation with real patient therapeutic drug monitoring (TDM) and outcome data is required before any clinical use.**

### Files not included (regenerable; see "How to regenerate" below)

- `models/phase2_popk_trace_likelihood.nc` (~629 MB) — full Bayesian posterior trace, regenerable with `python refit_popk.py`
- `models/phase2_popk_trace.nc` (~170 MB) — legacy prior-predictive trace, regenerable with `python phase2_population_pk.py`

Both files exceed GitHub's 100 MB single-file limit; they are listed in `.gitignore`. The headline parameter summary (mean, SD, HDI, R̂, ESS for every reported parameter) is included in `results/phase2_diagnostics/parameter_summary_likelihood.csv`, and the script below regenerates the full trace in roughly 20–40 minutes on a modern CPU.

## How to reproduce the analyses end-to-end

The full pipeline takes ~1.5 hours on a modern CPU (no GPU required). Each phase consumes only the artifacts of the previous one.

```bash
# Phase 1 — Preprocess raw simulated data
python phase1_preprocessing.py

# Phase 2 — Likelihood-conditioned Bayesian PopPK refit (recommended)
#   Writes models/phase2_popk_trace_likelihood.nc and
#   results/phase2_diagnostics/parameter_summary_likelihood.csv
#   Takes ~20–40 min on CPU with nutpie sampler
python refit_popk.py
# Smoke test (50 patients, 200 draws, ~2 min) before committing to a full run:
python refit_popk.py --smoke

# Phase 3 — PK/PD indices, target attainment, outcome models
python phase3_pkpd_modeling.py

# Phase 4 — XGBoost/LightGBM/CatBoost training with Optuna + SHAP
python phase4_machine_learning_enhanced.py

# Phase 5 — Multi-objective Bayesian dose optimization
python phase5_dose_optimization.py

# Regenerate manuscript figures (writes into ./figures/)
python generate_manuscript_figures.py
```

### One-off: regenerate the synthetic cohort

The `data/` and `data/processed/` folders are already included; the analyses are deterministic given a fixed seed and will produce the published numbers when re-run on the committed CSVs. If you want to regenerate the entire cohort from scratch:

```bash
python generate_synthetic_data_python.py
python phase1_preprocessing.py
# then proceed with refit_popk.py etc. as above
```

## Key reproduced numbers (from the post-refit pipeline)

| Quantity | Value |
|---|---|
| Cohort size | 1,500 synthetic ICU patients (945 amikacin, 555 gentamicin) |
| PopPK | Two-compartment, 2 chains × 1,000 draws, R̂ ≤ 1.03 |
| θ_CL (gentamicin baseline) | 4.36 L/h (94% HDI 4.28–4.46) |
| Amikacin typical CL | 3.33 L/h (4.36 × e^−0.27) |
| β_CL,CrCL / β_CL,WT / β_Vc,WT | 0.322 / 0.148 / 0.134 (HDIs narrow) |
| β_CL,Age | −0.020 (HDI crosses 0; not credible) |
| σ_prop / σ_add | 0.146 / 0.394 mg/L |
| Pre-dose nephrotoxicity AUROC | **0.799** (26 features) — clinically deployable |
| Post-dose nephrotoxicity AUROC | 0.915 (55 features) — positive-control |
| Clinical-cure AUROC | 0.964 |
| Dose-optimization deltas | −21.0% simulated nephrotoxicity · +1.7% simulated cure (mean 1,335 → 845 mg) |

Detailed parameter table: `results/phase2_diagnostics/parameter_summary_likelihood.csv`.

## Repository status flag for editors

This is a **research-grade reproducibility package**, not a clinical-deployment-ready software product. It is provided for:

1. Editorial peer review of the methodology and reported numerical results.
2. Independent replication of all figures, tables, and headline statistics in the manuscript.
3. Adaptation to other synthetic cohorts (e.g., regional population recalibration) before any prospective clinical use.

External prospective validation with real patient TDM and outcome data is required before clinical interpretation. The pre-dose model (26 admission features, AUROC 0.799) is the candidate intended for prospective evaluation; the post-dose AUROCs (0.915, 0.964) are reported as positive-control evidence that the modeling pipeline recovers the simulator's embedded PK/PD-to-outcome mapping.
